# Paper Experiments

This folder collects the experiment code currently used by the paper draft.

Contents:
- `LLM_paper_qwen25/`: controlled and real-world Qwen2.5-based LLM experiments
- `data_hyper_cleaning/`: MNIST label-noise hyper-cleaning experiments
- `imbalance_data/`: MNIST imbalanced-loss-tuning experiments

Notes:
- This package is intended to be git-friendly.
- It excludes large output directories and Slurm logs.
- Existing root-level paths are preserved through symlinks, so the rest of the repo still works.
